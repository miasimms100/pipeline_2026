# pipeline_2026
Pipeline Repository for Summer 2026 cohorts

## Project Structure

- **assets/**: This folder will be used to organize images used in the app layer of the project.
- **data/**: This folder will be used to store CSV outputs of API calls to the weather app.
  - **Weather Data Processing**: The weather code file serves as a reference to convert numerical weather codes from the API into relatable text descriptions of weather events for each day (e.g., converting code 0 to "Clear sky" or code 61 to "Rain").
