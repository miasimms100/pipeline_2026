# pipeline_2026
Pipeline Repository for Summer 2026 cohorts

## Project Structure

- **assets/**: Images and media used in the app layer of the project.
- **data/**: CSV outputs and reference files for weather data processing.
  - `daily_weather_forecast.csv`: Processed 16-day weather forecast data (generated by main.py)
  - `weather_codes.xlsx`: Reference lookup table mapping weather codes to descriptions

## Scripts

### app.py
**Purpose**: Dash weather recommendation app for Louisville attractions.

**Workflow**:
1. Reads `data/daily_weather_forecast.csv`
2. Enriches weather codes with descriptions from `data/weather_codes.xlsx`
3. Reads attraction details and category flags from `data/tourism.csv`
4. Scores attractions using simple weather and category rules
5. Displays Plotly temperature and precipitation charts with recommendation cards

**Usage**:
```bash
python app.py
```

### main.py
**Purpose**: Production pipeline that fetches weather forecast data and merges it with weather code descriptions.

**Workflow**:
1. Fetches 16-day weather forecast from Open-Meteo API for Louisville, KY
2. Transforms Unix timestamps to readable dates and times (HH:MM format)
3. Loads weather code reference from `data/weather_codes.xlsx`
4. Splits comma-separated weather codes into individual rows
5. Merges forecast data with weather descriptions using left join on weather_code
6. Exports processed data to `data/daily_weather_forecast.csv`

**Key Features**:
- Handles missing data gracefully with error checking
- Expands multiple codes per description into separate rows
- Converts all timestamps to America/New_York timezone
- Outputs in Fahrenheit, inches, and mph

**Usage**:
```bash
python main.py
```

### api_practice.py
**Purpose**: Educational script demonstrating API calls, data transformations, and pandas operations.

**Demonstrates**:
1. **API CALL 1**: Open-Meteo Forecast API using `requests` library
   - Shows how to construct API parameters
   - Explains each parameter's purpose (timezone, units, forecast_days, etc.)
   - Demonstrates raw HTTP requests and JSON parsing

2. **DATA PROCESSING 1-2**: DataFrame creation and time transformations
   - Converting Unix timestamps to readable dates
   - Formatting sunrise/sunset times to HH:MM
   - Loading Excel files with `pd.read_excel()`

3. **DATA PROCESSING 3-4**: Data expansion and merging
   - Splitting comma-separated values with `str.split()` and `explode()`
   - Type conversion and validation with `pd.to_numeric()`
   - DataFrame merging with different join types

4. **DATA PROCESSING 5**: Exporting data
   - Saving DataFrames to CSV with `to_csv()`

5. **API CALL 2**: Alternative API approach using `openmeteo_requests` library
   - Shows library wrapper approach vs. raw requests
   - Demonstrates current weather data retrieval
   - Explains variable ordering and data access patterns

**Usage**:
```bash
python api_practice.py
```

**Learning Outcomes**:
- Understand RESTful API concepts (endpoints, parameters, responses)
- Learn pandas DataFrame operations for data transformation
- Master timestamp handling and timezone conversion
- Practice data merging and joining techniques

## Data Reference

### Weather Code Reference
The `data/weather_codes.xlsx` file contains:
- **Code**: Weather condition code(s) from the API (single or comma-separated)
- **Description**: Human-readable weather condition description

Example mapping:
- Code 0 → "Clear sky"
- Codes 1,2,3 → "Partly cloudy"
- Codes 45,48 → "Foggy"
- Code 61 → "Rain"

- Generous rate limits for educational use
